Service · Security

MCP & AI-agent security

Leslie Kadenge · reviews of the servers that hand AI models real tools and data

An MCP server gives an AI model the keys to something real — a database, a filesystem, a cloud account, a web session. I read those servers and tell you, with a test behind every finding, whether the keys can be misused. The result is a document you can forward to whoever asked: an enterprise customer's security team, a compliance reviewer, a partner's vendor questionnaire.

Most funded companies' servers are now designed well. Almost none can independently show it — their own tests prove their own assumptions. That gap, between a safety property you assert and one someone has verified, is the work.

What I do

Review — you have a server; I read the whole thing and write up what I find, each finding with a test. Fixed price, about a week.

Remediate — I don't just find the gaps, I close them: tool annotations, confirmation before destructive actions, re-validation, defense in depth — each with a test behind it, so your server leaves the review fixed, not just diagnosed.

Verify — your server is already good; I produce the independent write-up that proves it, for the customer or auditor who's asking who checked.

Build — you have a product and no server yet; I build one properly — annotations, an access model, guardrails, tests, CI — from day one.
